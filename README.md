# Design and Analysis of Algorithms — CSE 408

Reading material for the **Design and Analysis of Algorithms** course (CSE 408), written unit by unit.

Each unit is a single self-contained Markdown file: full theory, every definition explained, worked
numerical examples, traces, proofs, practice questions with solutions, and a revision sheet.

## What is inside Unit 1

- **Sections 1–6** — what an algorithm is, the RAM model, time vs space complexity,
  best/worst/average case, all five asymptotic notations with formal proofs, and growth-rate rules.
- **Sections 7–9** — analysing iterative algorithms with summations, then complete analyses of
  **insertion sort** (loop invariant, line-by-line cost table, all three cases) and
  **merge sort** (full trace, recurrence solved three different ways).
- **Sections 10–13** — writing recurrences from code, then the **substitution method**,
  the **recursion tree method** and the **master theorem** (including the extended form and the
  cases where the master theorem fails).
- **Sections 14–16** — the **divide-and-conquer** template, **Strassen's matrix multiplication**
  (seven products, verified by hand on a numerical example) and **order statistics** —
  quick select, k-th smallest, k-th largest, and median of medians.
- **Sections 17–18** — 30 practice questions with full solutions, 25 rapid-fire MCQs,
  a list of common mistakes, and a one-page revision sheet.
